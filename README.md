# FRZ

Ressources FiveM pour le serveur **FRZ RP**.

Ce dépôt contient les scripts et ressources custom développés pour le serveur FRZ RP.

## Ressources

| Nom | Description |
| --- | --- |
| `frz-rp-spawn` | Spawn à l'aéroport de Los Santos au premier join avec cinématique d'atterrissage d'avion et annonce vocale française. |

## Installation

1. Cloner ce dépôt dans `resources/[frz]/` de votre serveur FiveM :
   ```bash
   cd resources
   mkdir -p [frz]
   cd [frz]
   git clone https://github.com/matheo667-RMC/frz.git frz-rp-spawn
   ```
2. Ajouter au `server.cfg` :
   ```
   ensure frz-rp-spawn
   ```
3. Redémarrer le serveur.
